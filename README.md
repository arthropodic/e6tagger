# e6tagger
Tagging Tool for e621 Booru.
Depends on Mozilla based browser, doesn't work with re621 or Umami Extension.
Changes made with extension are YOUR responsibility. Use responsibly.

Contains a platform for the tagging project tool, and the tool creation form.
A tagging project is a tag changing tool that prompts you with options that make changes to posts. Tagging projects have criteria that a posts tags have to meet in order to be prompted for the options.

# How To Download:
1. Download This project, or clone main branch.
3. Go to the 'about:debugging' on a Mozilla based browser.
4. Click 'This Firefox', then click 'Load Temporary Add-on...', then select the 'manifest.json' file in this project.
If in private mode, set extension to be usable in private mode.

# How To Use:
1. Click popup, then click 'TaggingProjects/Settings'.
2. Create a new tagging project by filling out form with required data, or upload tagging project from computer.
3. Go to 'e621.net' & log-in.
4. Go to posts. Click popup, click tagging project. (Suggested) search for posts that would match the tagging projects criteria, Or click plus button beside tagging project in popup to add criteria to search.
5. Click popup, click tagging project.
6. Hover over post(s) highlighted in red.
7. Click option based on what you see within post.
8. Click popup, see change within queue. Click submit.
9. (optional) Explore features!
